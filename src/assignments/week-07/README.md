# Week 7 – Recreating an Inspirational Visualization

## Overview

For Week 7, I recreated an interactive sunburst visualization using React and D3. I chose this type of visualization because I liked how hierarchical information can be represented in a circular layout while still allowing the user to explore different levels of the data.

My goal was not to make an exact copy, but to use the original visualization as inspiration and recreate the main visual and interaction ideas within the React and D3 structure used in this course.

## Interaction

The visualization uses a hierarchical structure where the size and position of each arc represents its place in the hierarchy. Users can interact with the visualization to explore the different categories and see how smaller groups relate to larger ones.

This was especially interesting to me because the interaction makes a relatively complex dataset easier to explore without displaying everything as a traditional table or chart.

## What I Learned

Recreating this visualization helped me better understand how D3 handles hierarchical data, radial layouts, SVG paths, and interactive graphics. It also showed me how an existing visualization can be used as a reference while adapting the idea into a React application.
