# U.S. Consumer Price Index (CPI) Dataset

## Dataset Description

This dataset contains monthly Consumer Price Index (CPI) data for the United States. The CPI measures changes in the prices consumers pay for goods and services over time and is commonly used as an indicator of inflation.

I selected this dataset because my final project ideas focus on exploring inflation, consumer spending, and other economic indicators in the United States.

## Source

The dataset was downloaded from the Federal Reserve Economic Data (FRED) database.

Series: Consumer Price Index for All Urban Consumers: All Items in U.S. City Average (CPIAUCSL)

Source: U.S. Bureau of Labor Statistics via FRED.

https://fred.stlouisfed.org/series/CPIAUCSL

## Attributes

| Attribute | Type | Description |
|---|---|---|
| DATE | Time (Date) | The month and year of the CPI observation. |
| CPIAUCSL | Quantitative | The Consumer Price Index value for that month. |

## Potential Use

This dataset can be used to visualize how consumer prices have changed over time. For my final project, I may combine it with consumer spending and interest-rate data to explore relationships between major U.S. economic indicators.
